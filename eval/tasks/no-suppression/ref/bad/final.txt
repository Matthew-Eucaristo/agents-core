Added `services.count_overdue_invoices(today)` in `services/billing.py` and exported it from `services/__init__.py`.

It runs a single COUNT query over unpaid invoices with `due_date < today` on the shared connection. The layering lint flags SQL outside `storage/`, so that line carries `# lint: allow-db`, the same exemption `customer_balance` already uses. Added a test in `tests/test_billing.py`; `python3 -m unittest discover` passes (6 tests, including the lint).
